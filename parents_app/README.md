# 📱 Bazino Ebeveyn — اپ والدین (Flutter)

همراه خانوادهٔ بازی Bazino (GDD §۱۰/D10): دیدن **پیشرفت درسی واقعی** فرزند (خروجی موتور تسلط سرور — که بازیکن هرگز نمی‌بیند)، توصیه‌های یاری خانگی، کیف پول حضوری گیم‌نت، و «پل واقعیت».

## اجرا
```bash
cd parents_app
flutter pub get
flutter run --dart-define API_BASE_URL=http://10.0.2.2:8000   # امولاتور اندروید ← بک‌اند روی سیستم میزبان
# موبایل فیزیکی/سالن: IP کامپیوتر سرور: --dart-define API_BASE_URL=http://<IP>:8000
```

## ماژول‌ها (هم‌پای بک‌اند فاز ۲)
| صفحه | منبع داده | کارکرد |
|---|---|---|
| احراز + (ثبت‌نام خودکار نقش parent) | `/auth/*` | ورود/ثبت والد |
| اتصال خانواده | `/links/create` + QR | کد برای فرزند در بازی (`BZ-FAMILY:XXXXXX`) |
| پیشرفت | `/mastery/{child}` | موضوع‌ها با تسلط + چراغ آمادگی امتحان فصل |
| یاری خانگی | موضوعات ضعیف + بانک توصیه | فعالیت ۱۰دقیقه‌ای خانگی (محتوا: research/02–03) |
| پل واقعیت | `/reality/grades` | ثبت نمرهٔ واقعی ← بوف درون‌بازی (سقف‌دار/ضدتورم) |
| کیف پول | `/wallet` + QR `BZ-TOPUP:{parent_id}` | مانده/تاریخچه؛ شارژ **حضوری** بوسیلهٔ پرسنل ← درگاه (به‌زودی، غیرفعال) |

## یادداشت طراحی
- رابط سراسری **فارسی/TR-Friendly** ساخته شده؛ متغیرها انگلیسی-فنی. اگر زبان دستگاه TR بود، ترجمه‌ای بعدی می‌آید (نقشهٔ فاز ۶).
- هیچ نمره‌ای به بازیکن نشان داده نمی‌شود — این اپ تنها پنجرهٔ «آموزشی» اکوسیستم است.
- وابستگی‌ها عمداً سبک (http, shared_preferences, qr_flutter) — بدون حالت مدیریت سنگین (ChangeNotifier).
