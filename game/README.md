# 🗺️ Bazino — Kıbrıs Macerası (ماجراجویی قبرس)

بازی آموزشی آنلاین **سه‌زبانه (Türkçe • English • فارسی)** برای دانش‌آموزان **۱۲ تا ۱۸ ساله** قبرس شمالی،
که محتوایش دقیقاً بر اساس سرفصل‌های رسمی وزارت آموزش و فرهنگ KKTC (پوشه `research/`) طراحی شده است.

## اجرا (Run)
هیچ وابستگی و مرحله build ندارد — فقط کافی است به‌صورت استاتیک سرو شود:

```bash
cd game
python3 -m http.server 8080 --bind 0.0.0.0
# → http://localhost:8080
```

یا هر هاست استاتیک دیگر (GitHub Pages, Netlify, …).

## ۶ منطقه نقشه + باس نهایی
🧮 ریاضی (Güzelyurt) · 🔬 علوم (Gazimağusa) · 🇬🇧 انگلیسی (Girne) · 🏛️ تاریخ (Lefkoşa) · 🗺️ جغرافیا/محیط‌زیست (İskele) · 🧩 ذکا (Lefke)
و **🎓 سالن امتحان**: شبیه‌سازی واقعی آزمون Yerleştirme — ۱۰ سؤال در دو سانس، ۸ دقیقه، **حدنصاب ۶۰٪، بدون نمره منفی** (دقیقاً قواعد آزمون ملی).

## مکانیک‌های کلیدی (از قلب پژوهش)
- **پاداش دوزبانگی (Dil Bonusu)**: پاسخ انگلیسی به سؤالات ریاضی/علوم = ‏+۱۰٪ XP — اقتباس از «%5 Dil Katkı Puanı» آزمون واقعی.
- **بدون سوختن امتیاز**: خطا فقط قلب‌ها را کم می‌کند، امتیاز کسب‌شده هرگز از بین نمی‌رود (قانون «۴ غلط ۱ درست را نمی‌برد»).
- XP، سطح، سکه (Altın)، استریک 🔥، ۸ دست‌آورد، باز شدن تدریجی مناطق، بهترین رکورد امتحان.
- ذخیره‌سازی کامل در `localStorage` — بدون حساب کاربری (مناسب کودکان، بدون جمع‌آوری داده).

## افزودن سؤال جدید
در `js/data.js` یک سطر `r(...)` اضافه کنید:
```js
r("math",0,["Konu TR","Topic EN","موضوع FA"],
"سؤال ترکی","Question EN","سؤال فارسی",
["گزینه۱","۲","۳","۴"],0, // اندیس پاسخ درست
"توضیح ترکی","EN explanation","توضیح فارسی"),
```
- پارامتر دوم: `0`=لیگ نقره، `1`=طلا، `2`=الماس.
- گزینه‌ها می‌توانند یک آرایه مشترک یا سه آرایه جدا (TR/EN/FA) باشند.
