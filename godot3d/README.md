# BAZİNO 3D — پروژهٔ Godot 4.3 سه‌بعدی

بازسازی کامل سه‌بعدی بازی آموزشی BAZINO (همهٔ قابلیت‌های 2D + بیشتر). پروژهٔ دوبعدیِ `../godot/` **دست‌نخورده** به‌عنوان پشتیبان (fallback) باقی است.

## اجرا (۵ دقیقه)
1. Godot 4.3+ → **Import** → `godot3d/project.godot` → **F5**.
2. بدون هیچ دانلودی هم بازی اجرا می‌شود — مدل‌ها placeholder کم‌پلی‌اند تا پک‌های CC0 برسند.
3. **اختیاری — مدل‌های واقعی Quaternius (CC0):** از quaternius.com/packs دانلود کن و به `godot3d/assets/external/` بریز (RPG Characters + Ultimate Animated Character Pack / Nature). آن‌ها در git نمی‌آیند. نقطهٔ اتصال آماده است: `Player3D.node_ready_with_model(model, anims)`.

## سیستم‌ها (نقشهٔ فایل)
- **ورودی/هسته:** `core/game_3d.gd` (عنوان → ورود/مهمان → انتخاب ۷ جزیره/فصل/هفتگی/فینال/سالن/کوآپ → راهرو و مراحل زنجیره‌ای)
- **بازیکن:** `player/player3d.gd` (پرش HK، دش، کمبو، آسیب/nok-bak/respawn) + `player/cam_rig.gd` (دوربین خود-چرخ، بدون ماوس، shake/fov-kick)
- **جهان:** `world/island.gd` (راهروی محوّود با ریل درخشان/سنگ/کریستال/غبار جادویی)، `world/rune_gate.gd` (پازل بایست‌وحل، زمان‌دار، shuffle، knockback، تلمتری)، `world/treasure.gd` (گنج فرمول)
- **دشمن:** `enemies/wisp.gd` (شناور تعقیبی)، `enemies/golem.gd` (تانک زمینی، root_crawler)، `enemies/spitter.gd` (تیرانداز با تیر مستقیم)، `enemies/boss_3d.gd` (سپر پازلی: معادله→ایستادن روی سکو→۴٫۵s آسیب‌پذیری؛ غلط/تأخیر=موج شوک؛ متغیر برای همهٔ ۷ باس با boss_cfg.name_key/color)
- **محتوا:** `world/stage_loader.gd` (فایل‌های stages_*.json + tournament.json + fallback S2→S1)، `world/topic_puzzles.gd` (پازل زنده از topic_id برای اتاق‌های تطبیقی سرور + نگاشت topic→tool)
- **تم:** `world/region_themes.gd` (رنگ/آسمان/مه/ترکیب دشمن هر جزیره)
- **UI:** `ui/hud_3d.gd` (قلب/لوم/کمبو/بنر/نوار باس/وینیت/منوی مکث)
- **جوس:** `core/fx.gd` (burst ذرات، hitstop، cam shake/fov kick)
- **شبکه (همان ۲بعدی):** `net/api.gd`, `net/telemetry.gd`, `net/coop_3d.gd` (ENet LAN، پورت 34197)
- **مشترک با ۲بعدی:** همان ۲۶ endpoint سرور، همان `data/*.json` + `i18n.csv` (سه‌زبانه)، همان ۱۵ صدای سنتزی + ۲ لوپ موسیقی. تلمتری با `dim: 3` ارسال می‌شود (سروهای موجود آن را کنار 2D جمع می‌کنند).

## سناریوهای تست سریع
1. **مهمان → جزیرهٔ ریاضی** → دروازه/نبرد/گنج → باس Eski Hesapçı تا پایان سه مرحله.
2. **ورود سرور** (`oyuncu@bazino.local / oyuncu123`) → نشانگر 🟢 → مراحل تطبیقی از `/adaptive/stage` (پازل‌ها از `topic_puzzles` ساخته می‌شوند) + ناهم‌رسان آفلاین در صورت قطعی.
3. **فصل ۲** — چیپ S2؛ برای درس‌های بدون داده فایل S1 می‌آید (برچسب (S1)).
4. **هفتگی** — با ورود باز می‌شود (۴ مرحله W1–W4).
5. **فینال فصل (Boss Rush)** — با کد سالن یا ۳ جزیرهٔ پاک‌شده؛ پایان = جایزهٔ grand با کد باجه.
6. **کو-اوپ LAN** — روی دو دستگاه یک شبکه: Host روی دستی، Join با IP دیگری؛ روح زرد همگام می‌شود.
7. **زبان** — مبداً مکث: 🇮🇷 فارسی / Türkçe / English، صفحه سریعاً سوئیچ می‌کند.
