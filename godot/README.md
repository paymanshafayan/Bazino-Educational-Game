# 🗡️ Bazino: Ada'nın Sırrı — کلاینت Godot 4 (فاز ۳→۶)

اکشن-ادونچر دوبعدی به سبک Hollow Knight (GDD §۱۱.۱). خروجی: اندروید (APK) + PC (Windows/Linux).

## اجرا در حالت توسعه
1. نصب **Godot 4.3+** (godotengine.org) — بدون .NET.
2. `Import` ← همین پوشه (`project.godot`) → Run (F5).
3. بک‌اند روی `http://127.0.0.1:8000` (پوشهٔ `server/`). آدرس دیگر: متغیر محیطی `BAZINO_API`.

## ویژگی‌های پیاده‌شده (v1)
- **Movement Feel First** (D7/HK): شتاب/اصطکاک، کایوت‌تایم + بافر پرش، دَش با i-frame، کامبوی ۳ضربه‌ای شمشیر نور، هیت‌استاپ، اسکواش.
- **منطقهٔ ریاضی — Matematik Vadisi (Güzelyurt)**: ۳ مرحله از فصل ۱ با ۴ دروازهٔ عددی (EBOB/EKOK، توان، رادیکال، اتحاد) — پاسخ با **ایستادن روی سکو**، نه پنجرهٔ سؤال.
- 🐉 **باس: Eski Hesapçı** — سپر معادله‌ای؛ ۳ فاز؛ ایستادن روی مقدار x درست ← فاز شکستن سپر.
- **دفترچهٔ فرمول**: ۴ توان قابل‌گشایی (گنجینه‌ها) با کارت بصری — نه درس‌نامه.
- **اتصال سرور** (autoload): `Api` (login/adaptive/venue) + `Telemetry` (صف آفلاین→همگام‌سازی؛ همان Payloadهای فاز ۲: `obstacle_solved{time_ms,retries,tool_correct}`).
- **Venue Mode**: ورود با کد ۶رقمی سالن ← نشانهٔ «مرحلهٔ هفتگی» باز می‌شود.
- منوی خوش‌آمد: انتخاب زبان **TR/EN/FA** + پایهٔ ۶–۱۲ + ورود یا «حالت مهمان آفلاین».
- بصری کد-محور: سیلوئت‌های Polygon2D، پارالاکس کوه/مه، نور توان‌ها — بدون فایل رسانه‌ای خارجی.

## کلیدها (ساختهٔ زمان اجرا — game.gd)

## خروجی نهایی (فاز ۶ — مستندات در export_presets.cfg)
- Windows/Linux: Export → Presets (اول Export Templates را دانلود کنید).
- **APK**: دانلود Android build template + JDK 17 + keystore release (امضای فروشگاه = نیازمند حساب سازمان — بلاکر مالک).
- ⚠️ محدودیت sandbox توسعه: باینری Godot در این محیط قابل دانلود نبود (CDN مسدود)؛ صحت کد با lint ایستا (`tools/godot_lint.py`) بررسی شد و اجرا نیازمند Godot روی دستگاه توسعه است.

## اتصال ساختار
`scenes/main.tscn` (ریشه) ← `scripts/core/game.gd` ← `stage_builder.gd` اتاق‌ها را از StageConfig سرور یا `data/stages_math_s1.json` (آفلاین) می‌سازد.
