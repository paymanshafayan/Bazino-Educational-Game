## 🚀 اجرای کل سیستم (توسعهٔ محلی)
```bash
# ۱) بک‌اند
cd server && python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
.venv/bin/python -m scripts.seed && .venv/bin/uvicorn app.main:app --reload
# مستندات: http://localhost:8000/docs · دمو: .venv/bin/python -m scripts.e2e_demo
# پنل باجهٔ گیم‌نت: http://localhost:8000/admin/ui  (ورود: staff@bazino.local / staff123)

# ۲) بازی — Godot 4.3+ را باز و پوشهٔ godot/ را Import کنید (راهنما: godot/README.md)

# ۳) اپ والدین
cd parents_app && flutter pub get && flutter run --dart-define API_BASE_URL=http://10.0.2.2:8000
```

## 🔑 اصول طراحی (از تصمیم‌های مالک — رجیستری D در GDD)
- **لذت اول**: هیچ پنجرهٔ سؤال/نمره‌ای در بازی نیست؛ پاسخ‌ها با بدن (سکو/سیم/اهرم).
- **یادگیری نامرئی**: موتور تسلط سروری از رفتار بازی، موضوعات ضعیف را در قالب تازه برمی‌گرداند؛ «قبولی درس» = تسلط پنهان ≥ ۷۰٪.
- **گیم‌نت**: مرحلهٔ هفتگی گروهی + فینال فصل فقط در سالن؛ جوایز **غیرنقدی** (کوپن ← دوچرخه/PS۵).
- **پرداخت سازگار با KKTC**: شارژ **حضوری** کیف‌پول در سالن؛ لایهٔ Sanal POS (İktisat/Near East) آمادهٔ فعال‌سازی پس از مدارک شرکتی.
- **فصل‌بندی سال تحصیلی**: فصل ۱ = Güz (سپتامبر–ژانویه)، هم‌پای امتحانات مدرسه.

## ⚠️ بلاکرهای مالک (خارج از کد)
