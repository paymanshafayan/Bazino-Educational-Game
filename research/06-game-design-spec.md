# سند ۰۶ — سند طراحی بازی آموزشی آنلاین «بازینو» (Game Design Spec v1.0)

> مبتنی بر اسناد ۰۱ تا ۰۵. مخاطب نهایی: دانش‌آموزان ۱۲ تا ۱۸ ساله قبرس شمالی (پایه‌های ۶–۱۲). نسخه MVP پیاده‌شده در پوشه [`game/`](../game) — این سند هم راهنمای توسعه و هم ریشهِٔ تصمیم‌های محصولی است.

## ۱. کانسپت

**«Bazino: Kıbrıs Macerası / ماجراجویی قبرس»** — بازیکن دانش‌آموزی است که روی نقشه شمال جزیره قبرس سفر می‌کند؛ هر شهر/منطقه = یک «قلعه علمی» با یک رشته درسی. با پاسخ درست به دوئل‌های سؤالی، منطقه فتح می‌شود، XP و سکه (Altın) جمع می‌شود، مناطق جدید باز می‌شود و در نهایت بازیکن در **«سالن امتحان»** (Sınav Salonu) با شیطنت‌گر نهایی آزمون واقعی — با قواعد واقعی آزمون ملی — روبه‌رو می‌شود.

**چرا جزیره/شهرها؟** چون «Kıbrıs Coğrafyası» و «Kıbrıs Türk Tarihi» درس‌های رسمی‌اند: نقشه بازی خودش ابزار یادگیری جغرافیای قبرس است (تم ترکیب آموزش + هویت محلی).

**بازکردن مناطق:** مناطق ۱–۳ از ابتدا آزاد؛ ۴ و ۵ با سطح ۳؛ ۶ با سطح ۵؛ باس نهایی با فتح حداقل ۴ منطقه.

## ۴. حلقه هسته گیم‌پلی (Core Loop)

```
نقشه → انتخاب منطقه → دوئل (دور ۸ سؤالی، ۳ قلب) → پاداش (XP/سکه/نشان)
   ← بازگشت به نقشه ← صفحه نتیجه (آمار: دقت، بهترین استریک، توضیح خطاها)
         ↺ تکرار برای تمرین | باز شدن منطقه تازه → سطح‌آپ → دست‌آوردها
```

**قواعد دوئل (برگرفته از فرهنگ آزمون فدرونی):**
- هر دور ۸ سؤال چندگزینه‌ای (۴ گزینه)؛ هر پاسخ غلط = از دست دادن ۱ قلب (۳ قلب در هر دور). تمام شدن قلب‌ها = دور ناموفق، بدون جریمه امتیازی — فقط دوباره تلاش.
- **بدون نمره منفی** (انطباق با قاعده آزمون ملی KKTC).
- **استریک**: هر ۳ پاسخ متوالی درست = ×۱.۵ امتیاز همان سؤال؛ هر ۵ تا = سکه پاداش.
- **Dil Bonusu پاداش دوزبانگی**: در مناطق ریاضی/علوم، دکمه‌ای جهت سوییچ لحظه‌ای زبان سؤال به انگلیسی؛ پاسخ درست به سؤال انگلیسی = **+۱۰٪ XP** (اقتباس مستقیم از «%5 Dil Katkı Puanı» آزمون واقعی که در بازی سخاوتمندانه‌تر شد).
- **توضیح آموزشی** پس از هر سؤال (اولین فرصت یادگیری = لحظه خطا).

**سیستم پیشرفت:**
- XP و **سطح** (آستانه‌های تجمیعی: ۱۰۰، ۲۵۰، ۵۰۰، ۸۰۰، ۱۲۰۰…) — Level ۳: باز شدن Lefkoşa/İskele؛ Level ۵: Lefke؛ فتح ۴ منطقه → باس.
- **سکه (Altın)** ← فعلاً برای نمایش ثروت + فروشگاه آینده (اسکین آواتار/رقص پیروزی).
- **دست‌آوردها (Achievement)**: İlk Doğru (اولین پاسخ درست)، Seri 5 (۵ پاسخ متوالی)، Kusursuz (دور بدون خطا)، Bölge Fatihi (فتح کامل یک منطقه)، Çift Dilli (۱۰ پاسخ با Dil Bonusu)، Sınav Şampiyonu (قبولی در باس ≥۶۰٪)، Haftalık Şampiyon…
- **ذخیره‌سازی:** localStorage (بدون حساب کاربری در MVP؛ مناسب سن و حریم خصوصی).

## ۵. زبان و محلی‌سازی

- ۳ زبان UI: **Türkçe (پیش‌فرض برای دانش‌آموز)، English، فارسی (برای تیم سازنده/بازار ایران)** — انتخاب در شروع + قابل تغییر در پروفایل.
- همه سؤالات سه‌زبانه در `data.js` با ساختار `q:{tr,en,fa}` و `o:{tr:[],en:[],fa:[]}`.
- راست‌به‌چپ شدن کامل UI در حالت فارسی (dir=rtl).

## ۷. طراحی «سالن امتحان» (باس — انطباق یک‌به‌یک با Yerleştirme سند ۰۴)

| قاعده واقعی | پیاده‌سازی در بازی |
|---|---|
| آستانه پذیرش ۶۰/۱۲۵ (≈۴۸٪→ برای سادگی **۶۰٪ پاسخ درست**) | حداقل ۶ پاسخ درست از ۱۰ ⇒ موفقیت |
| بدون نمره منفی | غلط‌ها سکه/XP کسب‌شده را نمی‌سوزانند |
| دو جلسه | دو «شیفت» ۵ سؤالی با استراحت نمایشی |
| تایمر جلسه‌ای | ۴ دقیقه هر شیفت (miniaturized) |
| سکه-پاداش زبان | سؤالات ریاضی/علوم با +۱۰٪ در حالت EN |
| نتایج فوری + لیست | کارنامه فوری + ثبت بهترین رکورد (localStorage) |

## ۸. تکنولوژی MVP

- وب‌اپ تک‌صفحه‌ای خالص HTML/CSS/JS (بدون فریم‌ورک، بدون build) → قابل اجرا روی هر هاست استاتیک/موبایل.
- UI تیره نوجوان‌پسند، کارت‌ها، انیمیشن CSS سبک؛ <audio> WebAudio برای جلوه‌های صوتی کوتاه (بدون فایل).
- ساختار: `game/index.html`, `game/css/style.css`, `game/js/data.js` (داده سه‌زبانه), `game/js/app.js` (موتور).
- قابلیت توسعه: افزودن سؤال = افزودن یک آبجکت؛ در آینده: API + حساب کاربری + فروشگاه آواتار + حالت کلاسی (معلم کد می‌دهد).

## ۱۰. معیارهای موفقیت MVP (قابل سنجش)

- بازیکن تازه < ۶۰ ثانیه به اولین سؤال می‌رسد (onboarding سبک).
- میانگین دقت کاربر در ۱۰ دور اول رو به بهبود (داده محلی).
- ≥۳۰٪ کاربران حداقل یک بار Dil Bonusu استفاده کنند (شاخص یادگیری دوزبانه).
- زمان جلسه هدف: ۵–۱۰ دقیقه برای نقره، ۱۰–۲۰ دقیقه برای الماس (موک).
