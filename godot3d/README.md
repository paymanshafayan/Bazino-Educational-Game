# BAZİNO 3D — پروژهٔ Godot 4.3 سه‌بعدی

نسخهٔ بازسازی‌شدهٔ سه‌بعدی بازی آموزشی BAZINO. پروژهٔ دوبعدی قدیمی در `../godot/` **دست‌نخورده** به‌عنوان پشتیبان می‌ماند.

## اجرا
1. Godot 4.3 باز کن → **Import** → `godot3d/project.godot` → **Run** (F5).
2. بدون دانلود هیچ مدلی هم بازی با placeholderهای کم‌پلی (کپسول بازیکن، سنگ/کریستال، دیوار رونیک) اجرا می‌شود.

## کنترل‌ها
| کلید | عمل |
|---|---|
| W A S D / جهت‌ها | حرکت (نسبت به دوربین) |
| Space | پرش (coyote + buffer) |
| Shift / K | دَش (i-frame) |
| J / X | ضربه (کمبوی ۳ ضربه‌ای) |
| E / F | تعامل |

دوربین خودکار پشت بازیکن می‌چرخد — به ماوس نیاز نیست.

## معماری
- **Autoload (همنام 2D):** `Api` / `Telemetry` / `SaveData` / `Sfx` — اسکریپت‌های net و core دقیقاً همان‌های 2D هستند؛ ۲۶ API سرور بدون تغییر کار می‌کند. Telemetry با `dim: 3` می‌رود.
- **i18n:** همان `data/i18n.csv` سه‌زبانه (fa/tr/en) با کلید `locale/translations`.
- **مدل‌های Quaternius:** credoti `assets/external/` دانلود می‌شوند و در git **نمی‌آیند**. در بازیکن نقطهٔ تعویض آماده است (`node_ready_with_model`)؛ تا آن حین کپسول placeholder است.

## وضعیت (چپتر A)
✅ هستهٔ موتور: کنترلر Hollow-Knight-وَر (coyote/buffer/dash/کمبو)، ریگ دوربین، جزیرهٔ کم‌پلی با مه/glow/Lum، دروازهٔ رونیک 3D (پازل روی صفحه‌ها)، دشمن Wisp تلمتری‌دار، صف عنوان، HUD (قلب + لوم)، ۱۵ صدای سنتزی و موسیقی ambient.

⏭ چپتر B: HUD کامل + ذخیره/اره‌کشی جزیره صفر، سپس C (ورود/ثبت‌نام به همان بک‌اندی) و check‑point اول بعد از چپتر D.
